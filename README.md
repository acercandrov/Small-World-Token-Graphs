# Small-World Token Graphs

*Autores:*  
Alejandro Vaca¹, GPT-5²  
¹Proponente conceptual  
²Desarrollo teórico y redacción colaborativa  

Este proyecto contiene un *white paper conceptual* que propone usar *topologías de mundo pequeño (small-world)* aplicadas al *espacio de tokens en modelos de lenguaje*. La idea es crear redes semánticas persistentes entre tokens para mejorar la memoria asociativa, la eficiencia cognitiva y la creatividad de modelos como los Transformers.

El white paper explora:
- Limitaciones de las arquitecturas Transformer actuales
- Propuesta de grafo small-world de tokens
- Dinámica de procesamiento y ventajas cognitivas
- Comparación con enfoques previos y aplicaciones futuras

## Archivos incluidos
- WhitePaper.pdf: PDF completo del white paper.
- WhitePaper.md: Versión Markdown para lectura en línea.
